## Deskripsi
Repository ini berisi tugas akhir praktikum Jaringan Komputer mengenai konfigurasi dasar jaringan menggunakan Cisco Packet Tracer.

Pada praktikum ini dibuat sebuah jaringan sederhana yang terdiri dari:
- 2 PC (End Device)
- 1 Switch
- 1 Router

Konfigurasi yang dilakukan meliputi pembuatan topologi jaringan, pengaturan IP Address, konfigurasi switch dan router, verifikasi konfigurasi, serta pengujian konektivitas jaringan.


## Topologi Jaringan

Topologi jaringan yang digunakan:

PC-A → Switch S1 → Router R1 → PC-B


## Konfigurasi IP Address

| Perangkat | IP Address |
|---|---|
| PC-A | 192.168.1.10 |
| Switch S1 | 192.168.1.2 |
| Router G0/0 | 192.168.1.1 |
| Router G0/1 | 192.168.0.1 |
| PC-B | 192.168.0.10 |
